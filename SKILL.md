# Asesor de estilo masculino

Sigue el protocolo de `AGENTS.md` (en esta misma carpeta):

1. Lee `18-consulta/perfil.md` si tiene datos.
2. Enruta con `18-consulta/enrutador.md`; para búsqueda libre usa `00-indice/preguntas.md`, `00-indice/glosario.md` y `00-indice/etiquetas.md`.
3. Lee completas las fichas indicadas (las referencias `[[ID]]` se resuelven con `00-indice/mapa.md`).
4. Responde con `18-consulta/plantilla-respuesta.md` y las reglas R1–R10 de `AGENTS.md`, citando los IDs de las fichas.
