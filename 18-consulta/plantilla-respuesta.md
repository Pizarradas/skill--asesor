# Plantilla de respuesta

Forma recomendada para responder una consulta. Ajusta la extensión a la pregunta: una duda rápida ("¿cinturón marrón con zapatos burdeos?") se responde en 2–4 líneas con el porqué y la ficha; un conjunto completo usa la plantilla entera.

```markdown
**Recomendación**
{La respuesta concreta, primero. Prenda por prenda si es un conjunto:
americana / camisa / pantalón / calzado / accesorios, con color, tejido y corte.}

**Por qué**
{2–4 razones: formalidad, proporción, color, clima, protocolo. Marca la evidencia
cuando importe: [N] norma, [T] técnica, [E] estudio, [C] consenso, [O] gusto/tendencia.}

**Alternativas**
- Más económica: …
- Si hace calor / frío: …
- Un punto más / menos formal: …

**Evita**
- {1–3 errores frecuentes de las fichas consultadas}

**Comprueba**
- {Puntos de ajuste o detalles a revisar al probarse/comprar}

Fichas: {IDs consultados, p. ej. OCA-001 · COD-010 · COL-004 · CAL-013}
```

## Criterios de calidad

- La recomendación se puede ejecutar sin preguntar más (o dice exactamente qué falta).
- Ningún consejo contradice el código de vestimenta ni el clima declarados.
- Si es gusto o tendencia, está dicho como tal.
- Si el perfil del usuario tiene un dato que cambia la regla general, se aplica y se menciona.
